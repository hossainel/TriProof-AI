# TriProof AI — compact session checkpoint

- **Server:** Laravel/MySQL API and bilingual web application. Local Apache + PHP 8.4-FPM serve `http://triproof.local`; the active databases are `triproof_ai` and `triproof_testing` on the system MariaDB service (3306). The old isolated 3307 service is stopped. Secrets belong in the ignored `.env`.
- **Android:** `android/` is a standalone Gradle project (Kotlin, XML/ViewBinding, min 26 / target 35). [Android setup and project tree](android/README.md). Bundled barcode/OCR models, pinned raw Ed25519 key, encrypted clock/identity, Room history and WorkManager cross-check/inbox. Demo labels use a separate trust root and never sync.
- **Mobile API additions:** authenticated `GET /api/v1/offline-blacklist`, `POST /api/v1/verify/transfer-ticket`, optional one-use `transfer_ticket` on cross-check. No database migration required. Per-device immediate feedback does not disclose the other owner's handle.
- **QR sticker printing:** local `chillerlan/php-qrcode` + GD PNGs, inline dompdf sheet at `GET /orders/{po}/qr-stickers?limit=2`; scoped `qrStickers` policy; English-only `O1/I1` … `O{n}/I{n}` pair badges and cut tags; `config('triproof.max_pdf_units')` bound. Dashboard, generation toast and verifier open a two-pair preview in a new tab.
- **Checks:** debug APK assembled and its signature verified; R8-minified release AAB built. Android lint, five JVM tests and seven API 35 instrumented tests passed. Bundled OCR and QR decoding ran with airplane mode enabled and no default network. Laravel: 51 tests / 247 assertions; Pint, Composer validation and Blade cache passed. QR test extracts all four embedded PNGs from the final PDF and decodes the exact serial pairs.
- **Latency:** warm offline packing, 45 distinct labels including Room commit, measured median 18.4 ms / p95 36.5 ms / maximum 62.6 ms on the emulator. Repeat p95 was 28.5 ms. The 50 ms target was met at p95, not on every scan.
- **Build downloads:** successful `main` runs of **Android scanner** attach the debug APK and unsigned release AAB. See [Android setup](android/README.md#run).

**Remaining for production:** (1) test latency and curved/low-light labels in airplane mode on a representative physical handset; no handset was attached at this checkpoint, and (2) configure the production HTTPS endpoint and independently verified public key, then sign the release bundle in the deployment pipeline.
